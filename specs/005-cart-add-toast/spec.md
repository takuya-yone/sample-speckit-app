# Feature Specification: カート追加時のトースト通知

**Feature Branch**: `005-cart-add-toast`
**Created**: 2026-04-24
**Status**: Draft
**Input**: User description: "カートに商品を追加した場合、メッセージを画面上に表示したい。shadcnを利用"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - カート追加時の確認メッセージ表示 (Priority: P1)

ユーザーが商品一覧ページで「カートに追加」ボタンを押した際、
画面上にトースト通知（一時的なメッセージ）が表示され、
どの商品がカートに追加されたかを即座に確認できる。
トーストは数秒後に自動的に消え、ユーザーの操作を妨げない。

**Why this priority**: カートへの追加操作に対するフィードバック
がないと、ユーザーは操作が成功したか不安になる。即時の
視覚的フィードバックはECサイトのユーザー体験において
不可欠な要素である。

**Independent Test**: 商品カードの「カートに追加」ボタンを
クリックし、画面上部（または右上）にトースト通知が表示
されることを確認する。通知には追加された商品名が含まれ、
数秒後に自動で消えることを確認する。

**Acceptance Scenarios**:

1. **Given** 商品一覧が表示されている, **When** 「カートに
   追加」ボタンを押す, **Then** 「[商品名]をカートに追加
   しました」というトースト通知が画面に表示される
2. **Given** トースト通知が表示されている, **When** 3〜5秒
   経過する, **Then** トーストが自動的にフェードアウトして
   消える
3. **Given** トースト通知が表示されている, **When** ユーザー
   が閉じるボタンを押す, **Then** トーストが即座に消える
4. **Given** 複数の商品を連続で追加する, **When** 各追加
   操作ごとに, **Then** それぞれの通知が重複せず順番に
   表示される（スタック表示）

---

### User Story 2 - 既存機能との統合 (Priority: P1)

トースト通知の追加により、既存のカート機能（追加、数量変更、
削除）や商品一覧の表示、ヒーローセクションなどの機能に
リグレッションが発生しないことを保証する。

**Why this priority**: 新機能の追加により既存機能が壊れる
ことは許容できない。

**Independent Test**: トースト通知を実装した後、カートへの
追加・数量変更・削除、商品画像の表示、ヒーローアニメーション、
レスポンシブレイアウトがすべて正常に動作することを確認する。

**Acceptance Scenarios**:

1. **Given** トースト通知機能を追加した, **When** カートに
   商品を追加する, **Then** カートのバッジ数とトースト通知
   の両方が正しく表示される
2. **Given** トースト通知機能を追加した, **When** カート
   ドロワーを開く, **Then** カート内の商品管理機能が
   正常に動作する
3. **Given** トースト通知機能を追加した, **When** ページを
   リロードする, **Then** カートの永続化が正常に動作する

---

### Edge Cases

- 連続して素早くカートに追加した場合、複数のトーストが
  重ならずスタック表示される
- ブラウザのアクセシビリティモードでもトースト通知が
  スクリーンリーダーに読み上げられる
- モバイル画面でもトーストが画面内に収まり、操作の邪魔に
  ならない

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: カートに商品を追加した際、画面上にトースト
  通知を表示する MUST
- **FR-002**: トースト通知に追加された商品名を含める MUST
- **FR-003**: トーストは3〜5秒後に自動的に消える MUST
- **FR-004**: ユーザーがトーストを手動で閉じられる MUST
- **FR-005**: 複数のトーストをスタック表示できる
  （同時に最大3件まで表示） SHOULD
- **FR-006**: トーストの表示・非表示にスムーズな
  アニメーションを適用する SHOULD
- **FR-007**: スクリーンリーダーがトースト通知を
  読み上げられる MUST

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: カートに追加してからトースト通知が表示される
  までの時間が0.5秒以内
- **SC-002**: トーストの自動消去が3〜5秒以内に完了する
- **SC-003**: 既存機能（カート操作、商品表示、アニメーション）
  の動作テストが100%合格する
- **SC-004**: モバイル・タブレット・デスクトップの全画面
  サイズでトーストが正しく表示される

## Assumptions

- トースト通知はカートへの商品追加時のみ表示する
  （数量変更や削除時は表示しない）
- トーストの表示位置は画面右上とする（EC サイトの標準的な
  慣習に従う）
- shadcn/ui のToastコンポーネントを使用する
  （ユーザーが明示的に指定）
- トースト通知のスタイルは既存アプリのデザイン（緑を
  基調としたテーマ）に合わせる
- トーストの同時表示数は最大3件とし、超過分は古いものから
  非表示にする
