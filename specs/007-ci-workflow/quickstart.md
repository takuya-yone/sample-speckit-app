# Quickstart: CI/CDワークフロー

## ワークフローの動作確認

### Pull Requestでの確認

1. フィーチャーブランチを作成してコミットする
2. mainブランチに対するPull Requestを作成する
3. GitHubのPRページで「Checks」タブを確認する
4. ワークフローが自動的に実行され、結果が表示される

### mainブランチへのPushでの確認

1. PRをマージする（またはmainブランチに直接Push）
2. GitHubの「Actions」タブでワークフロー実行を確認する

## ワークフローのローカルテスト

ワークフローで実行されるコマンドをローカルで確認:

```bash
# 型チェック
pnpm tsc -b

# リンティング
pnpm lint

# ビルド
pnpm build
```

## ワークフローの設定変更

ワークフロー定義ファイルは `.github/workflows/ci.yml` にあります。

### トリガーの変更

ブランチ追加やイベント追加が必要な場合は、`on` セクションを編集してください。

### ステップの追加

テストフレームワーク導入後にテストステップを追加する場合は、buildステップの前に追加してください。
